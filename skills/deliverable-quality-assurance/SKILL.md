# Deliverable Quality Assurance

## Overview
Enforces rigorous quality gates, checklist verifications, and compliance standards before any deliverable is presented to the client or user.

## When to Use
- When evaluating draft code, marketing copy, or technical documentation prior to milestone sign-off.
- When verifying that outputs satisfy all explicit items in division checklists.
- When catching hallucinations, incomplete code blocks, or broken links before client presentation.

## Core Capabilities
1. **Rubric-Based Evaluation**: Scores deliverables against qualitative and quantitative acceptance benchmarks.
2. **Defect Highlighting**: Pinpoints exact discrepancies, style violations, or logic flaws with actionable fix proposals.
3. **Approval Gating**: Prevents pipeline progression until critical and important defects are resolved.
