# Agency Persona Routing

## Overview
Evaluates user requirements across multi-disciplinary domains and routes objectives to specialized agency personas (Frontend Wizard, Security Auditor, Growth Strategist).

## When to Use
- When incoming requests require deep domain knowledge rather than generic text generation.
- When selecting between competing division capabilities (e.g. Design vs. Frontend Engineering).
- When initializing complex workflows requiring multiple specialized agent roles.

## Core Capabilities
1. **Division Mapping**: Classifies tasks across 18 distinct agency divisions (`divisions.json`).
2. **Affinity Matching**: Matches requirements against persona system prompts and deliverable specifications.
3. **Context Injection**: Equips selected personas with domain tools, schemas, and brand guidelines.
