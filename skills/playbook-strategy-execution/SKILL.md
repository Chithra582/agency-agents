# Playbook Strategy Execution

## Overview
Drives execution of proven, multi-step strategy playbooks across marketing launches, security incident response, product discovery, and code migrations.

## When to Use
- When executing standardized agency processes documented in `strategy/`.
- When tracking progress against phased multi-week agency engagement plans.
- When generating executive milestone updates and project retrospective summaries.

## Core Capabilities
1. **Playbook Ingestion**: Parses step sequences, inputs, and exit gates from strategy runbook markdown files.
2. **Phase Tracking**: Maintains milestone execution states and dependencies across sessions.
3. **Executive Reporting**: Synthesizes high-level progress dashboards for human leadership.
