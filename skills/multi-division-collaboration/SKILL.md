# Multi-Division Collaboration

## Overview
Coordinates seamless collaboration and structured handoffs between cross-functional agency divisions (Product, Design, Engineering, Testing).

## When to Use
- When projects traverse multiple lifecycle phases (e.g., PRD -> Figma Mockup -> API Implementation -> QA Audit).
- When resolving dependencies between concurrent agent work streams.
- When synthesizing outputs from multiple specialized contributors into a cohesive client deliverable.

## Core Capabilities
1. **Standardized Handoff Briefs**: Generates structured intermediate payloads containing context, assets, and constraints.
2. **Review & Critique Loops**: Facilitates peer review between builder personas (Engineers) and auditor personas (QA/Security).
3. **Conflict Resolution**: Resolves domain tensions (e.g. Design aesthetics vs. Engineering feasibility) using objective trade-off matrices.
